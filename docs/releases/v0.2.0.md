# Baseball Hour v0.2.0

A redesigned terminal interface: a shaded ballpark atlas, scoreboard cards with live bases and counts, and a full game view.

![Baseball Hour in demo mode](https://raw.githubusercontent.com/justinramos101/baseballhour/v0.2.0/docs/screenshots/atlas.svg)

## Install

Run it with npm, without installing:

```sh
npx baseballhour@0.2.0 --demo
```

Or use the installer. It chooses the native binary for macOS or Linux, verifies its SHA-256 checksum, and installs it in `$HOME/.local/bin`.

```sh
curl --proto '=https' --tlsv1.2 -fsSL https://raw.githubusercontent.com/justinramos101/baseballhour/v0.2.0/scripts/install.sh -o /tmp/baseballhour-install.sh
sh /tmp/baseballhour-install.sh --version v0.2.0
"$HOME/.local/bin/baseballhour" --demo
```

Use `baseballhour` for today's live schedule. Press `?` for help. The demo uses illustrative scores and makes no network requests.

## What's new

- The ballpark atlas uses an Albers projection with shaded land, coastal water, a graticule, and a scale bar. The selected ballpark glows and pings, and live ballparks pulse.
- Nearby centers the map on your place, with rings at true straight-line distances. Slates with games outside North America get a wider view with world coastlines.
- The slate groups games into live, upcoming, final, and schedule-change sections. Two-line cards show club colors, and live games show bases, outs, and the count.
- The scorebug shows every inning, hits and errors, the base diamond, and the count. Enter opens a full game view with game facts and a locator map.
- The header, tabs, and footer use three rows, which leaves more room for games.
- `--color auto|truecolor|256` falls back to the 256-color palette on terminals without truecolor. `--ascii` now writes ASCII only.

The release archives have SHA-256 files and GitHub build-provenance attestations. Verify provenance with `gh attestation verify <archive> --repo justinramos101/baseballhour` if you use the GitHub CLI.
