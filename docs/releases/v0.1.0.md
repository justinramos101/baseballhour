# Baseball Hour v0.1.0

Baseball schedules, scores, and a ballpark map in your terminal. MLB and four affiliated MiLB levels work without an account or API key.

![Baseball Hour in demo mode](https://raw.githubusercontent.com/justinramos101/baseballhour/v0.1.0/docs/screenshots/atlas.svg)

## Install

The installer chooses the native binary for macOS or Linux, verifies its SHA-256 checksum, and installs it in `$HOME/.local/bin`.

```sh
curl --proto '=https' --tlsv1.2 -fsSL https://raw.githubusercontent.com/justinramos101/baseballhour/v0.1.0/scripts/install.sh -o /tmp/baseballhour-install.sh
sh /tmp/baseballhour-install.sh --version v0.1.0
"$HOME/.local/bin/baseballhour" --demo
```

Use `baseballhour` for today's live schedule. Press `?` for help. The demo uses illustrative scores and makes no network requests.

## Included

- All games, followed teams, and nearby ballparks share one game selection.
- Date browsing, team search, local start times, game details, and a compact terminal layout.
- Cached schedules with visible age when the network is unavailable.
- Native macOS binaries for Apple Silicon and Intel.
- Static Linux binaries for ARM64 and x86_64.

The release archives have SHA-256 files and GitHub build-provenance attestations. Verify provenance with `gh attestation verify <archive> --repo justinramos101/baseballhour` if you use the GitHub CLI.

Read the [installation guide](https://github.com/justinramos101/baseballhour/blob/v0.1.0/docs/install.md) for manual downloads, source builds, and updates.
