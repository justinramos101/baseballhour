# Baseball Hour

Baseball schedules, scores, and ballparks in your terminal. Browse today's MLB slate, follow your teams, or find nearby games. MLB and four affiliated MiLB levels work without an account or API key.

![Baseball Hour showing the ballpark atlas, daily slate, and selected game](https://raw.githubusercontent.com/justinramos101/baseballhour/main/docs/screenshots/atlas.svg)

The screenshot shows synthetic demo data.

## Run

With Node.js and npm installed, run:

```sh
npx baseballhour
```

Try the offline demo:

```sh
npx baseballhour --demo
```

## Install

To keep the command installed, run:

```sh
npm install -g baseballhour
baseballhour
```

The package includes precompiled binaries for macOS and Linux on x86_64 and ARM64. No Rust compiler or installation scripts are required.

Press `?` for the keyboard guide. Press `q` to quit.

## Update or remove

To update, run:

```sh
npm install -g baseballhour@latest
```

To remove, run:

```sh
npm uninstall -g baseballhour
```

See the [installation guide](https://github.com/justinramos101/baseballhour/blob/main/docs/install.md), [usage guide](https://github.com/justinramos101/baseballhour/blob/main/docs/usage.md), and [source repository](https://github.com/justinramos101/baseballhour).
