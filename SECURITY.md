# Security policy

## Report a vulnerability

Report a suspected vulnerability through a [private GitHub security advisory](https://github.com/justinramos101/baseballhour/security/advisories/new). Do not open a public issue for a vulnerability before the report has been reviewed.

Include the affected version, operating system, steps to reproduce, expected impact, and any proof-of-concept files that help reproduce the issue. Remove credentials and unrelated personal data from the report.

GitHub keeps the advisory private while the report is assessed. The advisory can also hold discussion and fixes.

Use the public [issue tracker](https://github.com/justinramos101/baseballhour/issues) for non-sensitive bugs.

## Release line

The public release line is `0.1.x`. Check the [release page](https://github.com/justinramos101/baseballhour/releases) for the newest available version.
